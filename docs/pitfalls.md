# 已知陷阱与注意事项（避开踩坑）

> 来自实际项目总结，按经验重要性排序。

## 文件与路径

1. **文件名必须与磁盘一致**：程序里写死的文件名与实际磁盘不符会导致文件被安静跳过（`exists()=False` 不报错）。新增发票/月份时**先 Glob 核对实际文件名再写入**。
2. **反斜杠转义陷阱**：Python 源码中 `\7`、`\B` 等会被当作八进制/控制转义（如路径中的 `\7月份` 或 `D:\xxx` 必须写 `\\` 或用 `/`）。
3. 输出目录不自动清理：重跑时注意文件名区分，必要时手动删除旧文件。
4. 用户会不定期增改文件：**重跑前重新核对文件清单与银行文件**。

## 解析与匹配

5. 开票日期有两种格式："2026年07月22日" 与 "2026-07-22"，月份提取需兼容两种。
6. PDF 文本含空格："合 计 ¥ 6.60 ¥ 0.40"（正则用 `\s*`）；"（小写）"可能全角/半角括号、与金额间可能有空格。
7. 红字发票原票号字段是"被红冲蓝字数电发票号码"（非"原发票号码"），两种模式都要提取才能配对冲红。
8. 是否红票判定：文件名含"红"即判红（"已冲红"也含红字，需用配对逻辑排除原票）。
9. 科目归类优先级：机票/探亲 → 职工福利费；客票 → 差旅费；软件/技术/服务 → 技术服务费；印刷/文具/展示/印油 → 办公费；餐饮 → 业务招待费（**服务判断不能先于机票判断**）。

## 工具与系统

10. PowerShell 输出中文乱码属正常显示问题，文件内容正常，勿据此误判。
11. 写文件必须 UTF-8。
12. PowerShell 5.1 不支持 `&&`，用 `;` 或 `if ($?) {}` 串联命令。
13. 加密的 xls 无法用工具破解，向用户索取密码或让用户粘贴数据（勿反复尝试猜密码）。
14. LibreOffice 安装/升级需 UAC 提权；权限不足时安装返回 1603。
15. 校验 jsonc 配置：用 `json.loads` 直接读原始内容（正则删注释会误删 URL 中的 `//`）。

## 业务口径

16. 发票口径 ≠ 银行口径（如发票含待报销金额、全额票据），费用总计以银行口径为准，在备注中说明差异。
17. 垫付费用、冲红发票、探亲报销比例等口径见交接文档/核对链文档，确认后再改账。
18. 报表中无数据的科目必须列示填 0（"没有的项目在表格里也要出现"）。
