# 真实性核对链（Verification Chain）

> 生成/更新任何报表或申报台账后，必须逐条验证以下核对链。**核心原则：所有数字来自原始文件（银行 XLSX / 发票 PDF / 员工名单），禁止编造。**

## 铁律

1. 不猜、不编：对不上先查原始文件，再查代码逻辑
2. 每条核对都必须成立，重跑后逐一验证
3. 生成任何报表后必跑 `verify_chain.py`，全部 PASS 才可交付

## 核对链条目

| # | 规则 | 说明 |
|---|---|---|
| 1 | 发票金额 = PDF「（小写）」后的数；税额 = 「合计」行第二个数 | 税额处理取决于纳税人身份：小规模不可抵扣 → 计入成本；一般纳税人可认证抵扣 → 进项税额单列 |
| 2 | 银行借方合计 = 期间费用合计 | 合同期费用来自费用明细（银行口径） |
| 3 | 现金流入 = 实收资本 + 银行验证款 | 投资款计入实收资本（非收入、不征所得税） |
| 4 | 期末余额 = 贷方合计 − 借方合计 | 结构化校验，脚本自动实现 |
| 5 | 冲红发票合计 = 0 | 正负相抵，作废票不计费用 |
| 6 | 资产负债表平衡：资产总计 = 负债合计 + 所有者权益合计 | 负债与权益分列、全部国家统一科目 |
| 7 | 现金流量表期末余额 = 银行期末余额 | 经营 + 投资 + 筹资三部分合计 |
| 8 | 各期间相加 = 年报 | 月报相加 = 年报；Q2+Q3 = 年报；所得税累计逐期递增 |
| 9 | 增值税/所得税：无销售全 0、亏损不缴 | 实际利润额负数按 0 填报；无销售则销项税额/应纳税额 0（一般纳税人有留抵则结转下期） |
| 10 | 无数据的科目/栏次也要列示填 0 | "没有的项目在表格里也要出现" |

## 附加核对（含公式台账）

- 个税台账：累计减除费用 = 5,000 × 任职月数；收入为 0 → 应纳税所得额为 0
- 报表公式值：openpyxl 不计算值，用 LibreOffice 静态重算后读取再比对
- 发票口径与银行口径不一致属正常（如发票含待报销金额或全额票据），在备注中说明差异

## 常见口径（示例，按当期实际核对填入）

| 科目 | 口径 |
|---|---|
| 实收资本 | 各股东出资合计（投资款，非收入） |
| 银行验证款 | 银行/支付平台的测试验证收入 → 营业外收入 |
| 职工福利费 | 标准内实报实销的探亲路费等 → 不征个税 |
| 垫付费用 | 员工垫付未报销 → 挂其他应付款；报销后结清 |
| 冲红发票 | 作废不构成费用（正负相抵=0） |
