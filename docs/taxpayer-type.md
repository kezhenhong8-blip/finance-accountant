# 纳税人身份判定：小规模纳税人 vs 一般纳税人

> 增值税处理的第一步必须是**先确认纳税人身份**，再决定计税方式、申报周期与申报表样式。不确定时一律标注"待确认"询问用户，**禁止擅自假设**。

## 为什么重要（影响哪些申报）

| 维度 | 小规模纳税人 | 一般纳税人 |
|---|---|---|
| 增值税计税 | 简易计税：销售额 × 征收率（3%，优惠期 1%；不动产出租/出售等 5%） | 一般计税：销项税额 − 进项税额 − 上期留抵税额 |
| 进项税额 | 不可抵扣，税额并入成本 | 可凭专票/海关缴款书等认证抵扣 |
| 申报频次 | 按季（个别情形按月） | **按月** |
| 申报表 | 《增值税及附加税费申报表（**小规模纳税人适用**）》 | 《增值税及附加税费申报表（**一般纳税人适用**）》 |
| 发票 | 普票为主，可自开专票（仍按征收率） | 专票/普票均按税率开具 |
| 不受影响 | 企业所得税 / 个人所得税 / 工商年报 | 同左 |

**关键**：纳税人身份只影响**增值税及附加**。企业所得税（查账/核定征收 + 小微优惠）、个税、工商年报的处理规则与身份无关。

## 判定证据（按可信度从高到低）

1. **开票信息（最直接）**
   - 增值税专用发票按**税率** 13% / 9% / 6% / 0% 开具 → 一般纳税人
   - 无论普票专票都按**征收率** 1% / 3%（或 5%）开具 → 小规模纳税人
2. **申报表样式与周期**
   - 月度+《…（一般纳税人适用）》，含"进项税额/留抵"栏 → 一般纳税人
   - 季度+《…（小规模纳税人适用）》，简易计税 → 小规模纳税人
3. **销售额规模**
   - 连续 12 个月累计不含税销售额超过 500 万元 → 必须登记为一般纳税人
   - 未超过 500 万元 → 可保持小规模
4. **税务登记信息**
   - 营业执照 / 电子税务局"纳税人资格信息" / 税务开业登记载明的资格
5. **抵扣行为**
   - 存在进项税额勾选认证抵扣的记录 → 一般纳税人

## 判定流程

```
1. 收集证据：开票记录、申报表、销售额、登记信息（读原始文件，禁编造）
2. 证据充足且无矛盾 → 得出结论（小规模 / 一般）
3. 证据不足、缺失或自相矛盾 → 标注"待确认"，向用户询问确认
4. 报表生成前后各核验一次：计税方式与申报表样式必须与身份一致
5. 后续新增开票类型/销售额跨线 → 重新评估身份是否变化
```

## 身份变更情形

- **小规模 → 一般纳税人**：连续 12 个月销售额超 500 万，或纳税人自愿申请登记
- **一般纳税人 → 小规模**：仅在符合国家税务总局特殊规定时允许（当前无常态政策）；**登记为一般纳税人后不得随意转回**，涉及此类变更必须"待确认"并经税局确认
- 变更后需更换申报表样式、调整计税方式与进项处理，本文档的增值税规则均按新身份适用

## 附加税费（两种身份一致）

城建税 7% / 教育费附加 3% / 地方教育附加 2%，均按**当期实际缴纳的增值税**计算（各地教育附加比例以当地为准）。
