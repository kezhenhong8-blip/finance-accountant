# 税务申报格式与日历（tax-report-format）

## 申报日历
| 申报事项 | 频率 | 期限 | 渠道 |
|---|---|---|---|
| 个人所得税扣缴申报 | 每月 | 次月1-15日（节假日顺延），**零申报也要报** | 自然人电子税务局（扣缴端） |
| 增值税及附加税费（**一般纳税人**） | **每月** | 次月1-15日 | 电子税务局 |
| 增值税及附加税费（**小规模纳税人**） | 每季 | 4/7/10/次年1月 1-15日 | 电子税务局 |
| 企业所得税季度预缴（A类） | 每季 | 同增值税季报 | 电子税务局 |
| 企业所得税年度汇算清缴 | 每年 | 次年5月31日前 | 电子税务局 |
| 个税综合所得年度汇算 | 每年 | 次年3月1日-6月30日（**员工个人**在个税APP办理） | 个税APP |
| 工商年报（企业年度报告公示） | 每年 | 次年1月1日-6月30日 | 国家企业信用信息公示系统 |

> 节假日顺延按国家税务总局公告为准；具体期限以当年电子税务局提示为准。

## 0. 第一步：先判定纳税人身份（重要）
增值税处理前**必须先确认纳税人身份**（小规模 / 一般纳税人），再套用对应计税方式与申报表。判定证据与流程见 `docs/taxpayer-type.md`，要点：
- 开票税率 13%/9%/6%/0% → 一般纳税人；征收率 1%/3%/5% → 小规模纳税人
- 按月申报 + 进项抵扣 → 一般纳税人；按季申报 + 简易计税 → 小规模纳税人
- 证据不足/矛盾 → 标注"待确认"，询问用户，禁止擅自假设

## 0. 发票票种识别（与身份判定配套）
每张发票先定票种再处理（详见 docs/invoice-recognition.md，可用 `financial-check/scripts/invoice_detect.py` 自动识别）：
- **专票（含数电专票）**：税额可认证抵扣（一般纳税人）/ 计入成本（小规模）
- **普票（含数电普票）**：税额不可抵扣（一般纳税人除通行费电子普票、注明旅客身份信息运输凭证等特殊规定）
- **红字发票**：冲减原蓝字票，费用/进项同步红冲
- **铁路电子客票**：注明旅客身份信息可计入运输服务抵扣（一般纳税人）
- **支付回单/行程校验单**：非发票凭证，仅存档
- 票种不确定 → 标注"待确认"，不得按默认票种处理

## 1. 个税扣缴申报（扣缴端）
- 表样：《个人所得税扣缴申报表》（国家税务总局公告2020年第20号），栏次：收入额/免税收入/减除费用/专项扣除/专项附加扣除/其他扣除/准予扣除的捐赠额 + 累计列 + 累计应纳税所得额/税率/速算扣除数/累计应纳税额/减免税额/累计已预缴税额/本期应退(补)税额
- 累计预扣法：累计应纳税所得额 = MAX(0, 累计收入 − 累计减除费用 − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除 − 累计捐赠)
- 减除费用：5,000 元/月 × 任职月数（当年首次入职人员/实习学生按任职起算）
- 年度综合所得税率表（预扣预缴用）：≤36,000→3%/0；≤144,000→10%/2,520；≤300,000→20%/16,920；≤420,000→25%/31,920；≤660,000→30%/52,920；≤960,000→35%/85,920；以上→45%/181,920
- 本期应补(退) = 累计应纳税额 − 减免税额 − 累计已预缴
- 人员信息采集列：工号/姓名/证件类型/证件号码/国籍/性别/出生日期/任职受雇从业类型（雇员、实习学生（全日制学历教育）等）/入职年度就业情形（当年首次入职学生等）/手机号码/任职受雇从业日期/离职日期/是否扣除减除费用
- 职工福利费（如按规定标准内实报实销的探亲路费）不征个税，不计入申报收入；无票现金补贴需并入工资

## 2. 增值税及附加税费
> 先按第 0 节判定纳税人身份，再套用对应小节。

### 2.1 小规模纳税人适用（简易计税）
- 计税方式：简易计税（征收率 3%；优惠期 1%；不动产出租/出售等 5%；进项税额不可抵扣，计入成本）
- 栏次：应征增值税不含税销售额（3%/5%）、销售使用过的固定资产、免税销售额（小微企业/未达起征点/其他）、出口免税销售额、本期应纳税额、减征额、免税额、应补(退)税额、附加税费（城建税7%、教育费附加3%、地方教育附加2%，按实际缴纳增值税计算）
- 无销售额：全 0 零申报

### 2.2 一般纳税人适用（一般计税）
- 计税方式：应纳增值税额 = 销项税额 − 进项税额 − 上期留抵税额
- 税率：销售货物/加工修理修配 13%、交通运输/建筑/不动产租赁服务/销售不动产/转让土地使用权 9%、现代服务/生活服务/金融/增值电信等 6%、出口货物/跨境服务 0%
- 申报表：《增值税及附加税费申报表（一般纳税人适用）》栏目：按适用税率计税销售额、按简易办法计税销售额、免税销售额、出口免税销售额、销项税额、进项税额、上期留抵税额、进项税额转出、免抵退应退税额、按适用税率计算纳税检查应补缴税额、应抵扣税额合计、实际抵扣税额、应纳税额、期末留抵税额、附加税费（城建/教育附加/地方教育附加）
- 进项税额凭增值税专用发票、海关进口增值税专用缴款书、农产品收购发票/核定扣除、通行费电子发票、旅客运输服务凭证等认证抵扣；不可抵扣项目（集体福利/个人消费/简易计税项目等）需做进项税额转出
- 无销售额：销项税额 0、应纳税额 0（有留抵则期末留抵延续）

## 3. 企业所得税月(季)度预缴申报表（A类）
- 栏次：营业收入/营业成本/利润总额/特定业务应纳税所得额/不征税收入/免税收入、减计收入、加计扣除/弥补以前年度亏损/实际利润额/从业人数/资产总额（季初季末）/税率25%/应纳所得税额/减免税额/实际已缴纳/应补(退)
- 实际利润额 = 利润总额 + 特定业务 − 不征税收入 − 免税收入 − 弥补亏损；**负数按 0 填报**（亏损不缴）
- 小型微利企业优惠按当年度政策在"减免所得税额"填列

## 4. 工商年报
- 内容：企业基本信息（名称/统一社会信用代码/法人/地址/联系电话/邮箱/从业人数）、股东及出资信息（认缴/实缴金额与日期）、资产状况信息（资产总额/负债/所有者权益/营业总收入/主营业务收入/利润总额/净利润/纳税总额，**年度12月31日数据**）、社保信息（各险种参保人数/缴费基数/缴费金额，以社保系统为准）、对外担保/股权转让/网站网店等
- 资产状况数字必须与当年年度财务报表一致

## 通用铁律
- 所有数字来自原始文件（银行流水/发票 PDF/员工名单/财务报表），禁编造；待确认项（法人、注册地址、认缴资本、社保等）必须标注"待确认"，不得代填
- 报表中无数据的科目/栏次也要列示填 0
- 生成后必须运行 financial-check skill 的核对链验证
