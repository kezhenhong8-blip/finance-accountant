# 财务核对链验证（financial-check）

## 何时使用
每次生成或更新下列文件后，必须先跑核对链再交付：
- 银行流水明细 / 发票费用明细 / 资产负债表 / 利润表 / 现金流量表
- 个税扣缴申报台账、季度申报台账、工商年报填报
- 涉及"新月份/新季度/新年度"数据扩展后

## 核心铁律
1. **不猜、不编**：任何数字必须来自原始文件（银行 XLSX、发票 PDF、员工名单），对不上先查原始文件再查代码
2. 核对链每条都必须成立，重跑后逐一验证

## 核对链
1. 每张发票金额 = PDF"（小写）"后的数；税额 = "合计"行第二个数（税额处理取决于纳税人身份：小规模不可抵扣 → 计入成本；一般纳税人可抵扣 → 进项税额单列）
2. 银行借方合计 = 期间费用合计
3. 现金流入 = 实收资本 + 银行验证款
4. 期末余额 = 贷方合计 − 借方合计
5. 冲红发票合计 = 0（正负相抵）
6. 资产负债表平衡：资产总计 = 负债合计 + 所有者权益合计
7. 现金流量表期末余额 = 银行期末余额
8. 各期间相加 = 年报（月报相加 = 年报、Q2+Q3 = 年报、所得税累计逐期递增）
9. 增值税/所得税：无销售则销项税额/应纳税额 0（一般纳税人有留抵则结转下期）、亏损不缴（实际利润额按 0 填报）
10. 报表中无数据的科目也要列示填 0（"没有的项目在表格里也要出现"）

## 操作步骤
1. **识别发票票种**：对每张发票 PDF 运行 `scripts/invoice_detect.py`（专票/普票/数电票/红字/铁路客票/回单），规则见 docs/invoice-recognition.md；未确定票种不得按默认处理
2. 读取原始银行流水 XLSX（活期账户明细 sheet，交易行 = 有"交易时间"的行）
3. 运行验证脚本：
   ```powershell
   $env:PYTHONIOENCODING="utf-8"
   python "<本skill路径>/scripts/verify_chain.py" `
     --bank "{财务数据根目录}/公账文件/X月份.xlsx" `
     --debit <借方合计> --credit <贷方合计> --balance <期末余额> `
     --capital <实收资本> --verify <银行验证款> `
     --taxbook "{财务数据根目录}/个税申报/…年度台账.xlsx"  # 可选
   ```
   - `--debit/--credit/--balance`：当期期望值（按当期实际核对填入，禁编造）
   - `--taxbook`：含公式的 xlsx 台账，自动调用 LibreOffice 重算后校验
4. 逐个 sheet 抽查：发票明细金额与 PDF 一致、票种归类正确（专票税额可抵/不可抵按身份）、资产负债表平衡、利润表本期 = 现金流量净额
5. 全部 PASS 才可交付；任一 FAIL 先核对原始文件再重跑

## 配置
- Python：任意含 openpyxl 的 Python 3（`pip install openpyxl`）
- LibreOffice：可选，校验含公式台账时需要。用 `--soffice` 指定路径，默认依次尝试环境变量 `SOFFICE_EXE` 与系统 PATH 中的 `soffice`
- 环境注意：PowerShell 5.1 无 `&&`；写文件必须 UTF-8；控制台中文乱码属正常显示问题，不要据此误判文件内容出错
