# 申报表格式规范

> 原则：与税务局官方模板一模一样（栏次名称一字不差）+ 没有数据的栏次也要出现并填 0。

## 财务报表（8-sheet 国家标准版）

| Sheet | 要点 |
|---|---|
| 封面 | 公司信息、报告概要、冲红说明 |
| 银行流水明细 | 交易时间/流水号/借方/贷方/余额/凭证号/附言/对方账号/对方名称/对方开户行 + 合计行；无交易期间显示红色说明行 |
| 发票费用明细 | 按期间分区段（不同底色）+ 小计 + 冲红合计（=0）+ 费用合计（银行口径） |
| 资产负债表 | 左右双栏（资产 | 负债+所有者权益），单标题合并；国家统一科目全列：货币资金/交易性金融资产/应收票据/应收账款/应收款项融资/预付款项/其他应收款/存货/合同资产/其他流动资产/固定资产/在建工程/无形资产/长期待摊费用/递延所得税资产 + 短期借款/应付票据/应付账款/预收款项/合同负债/应付职工薪酬/应交税费/其他应付款/长期借款/长期应付款/递延所得税负债 + 实收资本/资本公积/库存股/盈余公积/未分配利润；合计/总计行高亮；**行次：资产部分、负债权益部分各自从 1 编号** |
| 利润表 | 营业收入/营业成本/税金及附加/销售费用/管理费用/研发费用/财务费用/营业利润/营业外收入/营业外支出/利润总额/所得税费用/净利润，本期 + 本年累计两列 |
| 现金流量表 | 经营/投资/筹资三大部分全部标准行（含小计、净额、期末余额） |
| 增值税申报表 | 小规模 3%，计税依据/免税销售额/出口免税/税款计算/附加税费全部栏次 |
| 企业所得税申报表 | A类月（季）度预缴，实际利润额/应纳税额/减免/已预缴/应补退全部栏次 |

## 个税扣缴申报表（扣缴端）

- 表样：《个人所得税扣缴申报表》（国家税务总局公告 2020 年第 20 号）
- 栏次：收入额/免税收入/减除费用/专项扣除/专项附加扣除/其他扣除/准予扣除的捐赠额 + 累计列 + 累计应纳税所得额/税率/速算扣除数/累计应纳税额/减免税额/累计已预缴税额/本期应退(补)税额
- 累计预扣法：累计应纳税所得额 = MAX(0, 累计收入 − 累计减除费用 − 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除 − 累计捐赠)
- 减除费用：5,000 元/月 × 任职月数（当年首次入职/实习学生按任职起算）
- 年度综合所得税率表（预扣预缴用）：

| 级数 | 累计预扣预缴应纳税所得额 | 税率 | 速算扣除数 |
|---|---|---|---|
| 1 | ≤ 36,000 | 3% | 0 |
| 2 | ≤ 144,000 | 10% | 2,520 |
| 3 | ≤ 300,000 | 20% | 16,920 |
| 4 | ≤ 420,000 | 25% | 31,920 |
| 5 | ≤ 660,000 | 30% | 52,920 |
| 6 | ≤ 960,000 | 35% | 85,920 |
| 7 | 以上 | 45% | 181,920 |

- 人员信息采集：工号/姓名/证件类型/证件号码/国籍/性别/出生日期/任职受雇从业类型（雇员、实习学生（全日制学历教育）等）/入职年度就业情形/手机号码/任职受雇从业日期/离职日期/是否扣除减除费用
- 职工福利费（标准内实报实销）不征个税，不计入申报收入；无票现金补贴并入工资

## 增值税及附加税费申报表（小规模纳税人适用）

- 栏次：应征增值税不含税销售额（3%/5%）/销售使用过的固定资产/免税销售额（小微企业/未达起征点/其他）/出口免税销售额/本期应纳税额/减征额/免税额/应补(退)税额/附加税费（城建7%、教育附加3%、地方教育附加2%）
- 无销售额：全 0 零申报

## 企业所得税月(季)度预缴申报表（A类）

- 栏次：营业收入/营业成本/利润总额/特定业务应纳税所得额/不征税收入/免税收入、减计收入、加计扣除/弥补以前年度亏损/实际利润额/从业人数/资产总额（季初季末）/税率 25%/应纳所得税额/减免税额/实际已缴纳/应补(退)
- 实际利润额 = 利润总额 + 特定业务 − 不征税收入 − 免税收入 − 弥补亏损；负数按 0 填报
- 小型微利企业优惠按当年度政策在"减免所得税额"列

## 工商年报

- 企业基本信息：名称/统一社会信用代码/法人/地址/联系电话/邮箱/从业人数
- 股东及出资信息：认缴/实缴金额与日期
- 资产状况信息（年度 12 月 31 日数据）：资产总额/负债/所有者权益/营业总收入/主营业务收入/利润总额/净利润/纳税总额——必须与年度财务报表一致
- 社保信息：各险种参保人数/缴费基数/缴费金额（以社保系统为准）
- 对外担保/股权转让/网站网店等；待确认项标注"待确认"，禁止代填
