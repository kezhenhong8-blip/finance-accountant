## 1. 项目概况

- 主体：**{公司名称}**，成立 **{成立日期}**，**小规模纳税人**（3% 简易计税，进项税额不可抵扣，税额并入费用成本）
- 银行：{开户银行}，账号 **{银行账号}**；购方税号 **{统一社会信用代码}**
- 任务：根据银行流水 XLSX + 发票 PDF 生成符合国家标准的财务报表，分月报 / 季报 / 年报输出到不同文件夹。
- 人员/投资方：{股东A（采购/出资）、股东B（出资/差旅）、投资方企业（实缴）}

## 2. 数据源与目录结构

```
{财务数据根目录}/
├── 公账文件/                  ← 银行流水 XLSX（每月一个）
├── 支出发票/                  ← 发票 PDF（按期间/Q 分组，含冲红票与报销凭证）
├── 员工名单/                  ← 人事名单（可能加密）
├── 个税申报/                  ← 个税扣缴申报年度台账（多 sheet、跨表公式自动累计）
├── 季度申报/                  ← 增值税（小规模）+ 企业所得税 A 类季报台账
├── 工商年报/                  ← 年度工商年报填报
└── 整理输出/                  ← 财务报表输出（月报/季报/年报 + 总表 + 个税申报）
```

## 3. 脚本与工具调度

- 主脚本：`{主脚本目录}/_process_job.py`
  - Phase 1：读银行 XLSX；Phase 2：解析发票 PDF + 冲红配对 + 科目归类；Phase 3：按期间配置生成 8-sheet xlsx
- 运行命令（**必须设 PYTHONIOENCODING=utf-8**）：
  ```
  $env:PYTHONIOENCODING = "utf-8"; python _process_job.py
  ```
- 工具约定：
  - 读文件/搜代码用 Read / Glob / Grep 工具；改文件用 Edit 工具（先 Read）
  - 临时文件放系统临时目录；PowerShell 5.1 无 `&&`，用 `;` 或 `if ($?) {}`
  - 依赖：openpyxl、pdfplumber 等
  - 新增发票/月份时，先 Glob 核对实际文件名再写入规格表
  - 报表公式重算用 LibreOffice 静态重算；生成/更新报表后必跑核对链

## 4. 关键数据事实与核对逻辑（保证真实性）

- 会计口径（与用户确认后写入）：投资款=实收资本（非收入）；银行验证款→营业外收入；冲红发票作废不计费用；探亲报销按公司制度比例；垫付费用挂往来、报销后结清；各科目归类规则。
- 银行流水：X 笔交易（借方合计 / 贷方合计 / 期末余额）。
- 期间费用口径（银行确认）：X 月 Y + X 月 Z = 年报 W。
- 人员信息：姓名、证件类型与号码、性别、出生日期、任职类型、入职日期、是否扣除减除费用；性别/出生日期可由身份证号推导。
- 个税申报结论：无工资支付 → 零申报；标准内报销津贴不征个税不入申报收入；累计减除费用=5000×任职月数。
- **真实性核对链**（见 docs/verification-chain.md）每条都必须成立，重跑后逐一验证。
- 发现任何数字对不上时：不要猜、不要编，先核对原始 PDF/XLSX 文本，再查代码逻辑。

## 5. 国家标准格式要求

每份报告固定 8 个 sheet，全部科目列示、无数据填 0：封面 / 银行流水明细 / 发票费用明细 / 资产负债表（左右双栏、单标题合并）/ 利润表（本期+本年累计）/ 现金流量表（经营投资筹资三部分）/ 增值税申报表 / 企业所得税申报表。详见 docs/formats.md。

## 6. 已知陷阱

- 文件名必须与磁盘一致；开票日期两种格式兼容；PDF 文本含空格；红票原票号字段名称两种；红票判定含"已冲红"；科目归类优先级；PowerShell 中文乱码正常；写文件 UTF-8；加密 xls 勿猜密码。详见 docs/pitfalls.md。

## 7. 扩展新期间（如新增月份）步骤

1. 新增发票 PDF 放入支出发票对应文件夹，在规格表追加精确路径
2. 更新/新增银行 XLSX（如 `8月份.xlsx`），同步读取路径与报销映射
3. 复制一份期间配置 dict，按当期实际核对填入数字（禁编造）
4. 若新增发票类型未覆盖，扩展科目归类函数
5. 跑脚本 + 按第 4 节核对链逐条验证全部报告
